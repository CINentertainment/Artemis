One-time Gumroad publication

  1. Review the product ZIP, proposed listing, price and license.
  2. Create a digital product on Gumroad and upload the reviewed ZIP.
  3. Set your chosen price and publish when ready.
  4. Use Gumroad’s test purchase function to check checkout and download delivery.
  5. Return here and enable sales reconciliation. Test purchases stay excluded from revenue.

Gumroad provides checkout and hosted download delivery after publication. Initial creation and file upload are dashboard steps; this package does not claim API publication.

What is operating autonomously?

Once enabled: scheduled provider sales refresh, conservative local reconciliation, saved cycle history and optional daily opportunity searches. File delivery is handled by Gumroad after you publish. Artemis must remain running for local cycles. Pausing prevents further pages; a provider request already in flight may finish.

This package does not send outreach, post marketing, issue refunds, change prices, transfer funds or infer that Artemis caused a sale. Your private Tailscale portal stays private; no public callback endpoint is required.
